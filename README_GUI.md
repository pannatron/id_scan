# คู่มือการใช้งานโปรแกรม GUI อ่านบัตรประชาชนไทย

## ภาพรวม

โปรแกรม GUI สำหรับอ่านบัตรประชาชนไทยอย่างต่อเนื่อง เหมาะสำหรับการเก็บข้อมูลจำนวนมาก เช่น โครงการลงทะเบียน การจัดกิจกรรม หรือการเก็บข้อมูลนักเรียน

## ฟีเจอร์หลัก

### 1. **การจัดการโครงการ**
- ใส่ชื่อโครงการและชื่อโรงเรียน
- ข้อมูลจะถูกบันทึกใน CSV พร้อมกับข้อมูลบัตร

### 2. **การอ่านบัตรอัตโนมัติ**
- ⚡ **ตรวจจับบัตรอัตโนมัติ**: โปรแกรมจะตรวจสอบบัตรอยู่ตลอดเวลา
- 🔄 **อ่านต่อเนื่อง**: เสียบบัตร → อ่านข้อมูล → ถอดบัตร → เสียบบัตรใหม่ → อ่านต่อ
- ✅ **ป้องกันข้อมูลซ้ำ**: ไม่เพิ่มข้อมูลบัตรเดิมซ้ำ

### 3. **แสดงข้อมูล**
- ตารางแสดงข้อมูลทั้งหมดที่อ่านได้
- นับจำนวนคนที่อ่านบัตรแล้ว
- ดูรายละเอียดเพิ่มเติมของแต่ละคน

### 4. **Export ข้อมูล**
- 📄 Export เป็นไฟล์ CSV
- รองรับภาษาไทย (UTF-8 with BOM)
- ชื่อไฟล์อัตโนมัติตามโครงการและวันที่

## การติดตั้งและรัน

### 1. เปิด Virtual Environment
```bash
cd python-smartcard-reader
source env/bin/activate  # macOS/Linux
# หรือ env\Scripts\activate  # Windows
```

### 2. รันโปรแกรม GUI
```bash
python gui_reader.py
```

## วิธีใช้งาน

### ขั้นตอนที่ 1: ตั้งค่าข้อมูลโครงการ
1. เปิดโปรแกรม
2. ใส่ **ชื่อโครงการ** ในช่องแรก (เช่น "ลงทะเบียนนักเรียนใหม่")
3. ใส่ **ชื่อโรงเรียน** ในช่องที่สอง (เช่น "โรงเรียนสาธิต")

### ขั้นตอนที่ 2: ตรวจสอบสถานะ Reader
- **สีเขียว** ✓: Reader พร้อมใช้งาน
- **สีแดง** ✗: ไม่พบ Reader หรือมีปัญหา
- **สีส้ม**: กำลังค้นหา Reader

### ขั้นตอนที่ 3: อ่านบัตร
1. **เสียบบัตรประชาชน** ลงใน reader
2. โปรแกรมจะอ่านข้อมูลอัตโนมัติ (ใช้เวลา 2-3 วินาที)
3. เมื่อเห็นข้อความ **"✓ อ่านสำเร็จ - รอถอดบัตร"** (สีเขียว)
4. **ถอดบัตรออก**
5. เสียบบัตรใหม่เพื่ออ่านคนต่อไป
6. ทำซ้ำจนครบทุกคน

### ขั้นตอนที่ 4: Export ข้อมูล
1. คลิกปุ่ม **"📄 Export เป็น CSV"**
2. เลือกตำแหน่งที่จะบันทึกไฟล์
3. ไฟล์จะถูกสร้างพร้อมชื่อแบบนี้: `โครงการ_โรงเรียน_วันที่.csv`

## สถานะต่างๆ

### สถานะ Reader
- **✓ พร้อมใช้งาน** (เขียว): ตรวจพบ reader และพร้อมใช้งาน
- **✗ ไม่พบ Reader** (แดง): ไม่พบ reader หรือไม่ได้เชื่อมต่อ
- **กำลังค้นหา...** (ส้ม): กำลังค้นหา reader

### สถานะบัตร
- **⏳ รอเสียบบัตรใหม่** (เทา): ไม่มีบัตรในเครื่อง พร้อมรับบัตรใหม่
- **🔄 กำลังอ่านข้อมูล...** (ส้ม): กำลังอ่านข้อมูลจากบัตร
- **✓ อ่านสำเร็จ - รอถอดบัตร** (เขียว): อ่านเสร็จแล้ว สามารถถอดบัตรได้
- **⏸️ บัตรใบเดิม - รอถอดบัตร** (น้ำเงิน): เป็นบัตรที่อ่านแล้ว กรุณาถอดออก

## ปุ่มต่างๆ

### 📄 Export เป็น CSV
- Export ข้อมูลทั้งหมดเป็นไฟล์ CSV
- รวมข้อมูล: เลขบัตร, ชื่อ, วันเกิด, เพศ, ที่อยู่, ฯลฯ
- เปิดได้ด้วย Excel, Google Sheets

### 🗑️ ลบข้อมูลทั้งหมด
- ลบข้อมูลทั้งหมดที่อ่านแล้ว
- ต้องยืนยันก่อนลบ
- ใช้เมื่อเริ่มโครงการใหม่

### 🔄 รีเฟรช Reader
- ค้นหา reader ใหม่
- ใช้เมื่อเพิ่ง เสียบ reader หรือมีปัญหา

### 👁️ ดูรายละเอียด
- เลือกรายการในตาราง
- คลิกเพื่อดูข้อมูลแบบเต็ม
- แสดงข้อมูลทั้งหมดรวมถึงที่อยู่

### ❌ ออก
- ปิดโปรแกรม
- ข้อมูลจะหายถ้ายัง ไม่ได้ Export

## รูปแบบไฟล์ CSV

ไฟล์ CSV จะมีคอลัมน์ดังนี้:

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| ลำดับ | เลขลำดับที่ |
| โครงการ | ชื่อโครงการ |
| โรงเรียน | ชื่อโรงเรียน |
| เลขบัตรประชาชน | เลขบัตร 13 หลัก |
| ชื่อ-นามสกุล (ไทย) | ชื่อภาษาไทย |
| ชื่อ-นามสกุล (อังกฤษ) | ชื่อภาษาอังกฤษ |
| วันเกิด | วันเกิด (DD/MM/YYYY) |
| เพศ | ชาย/หญิง |
| หน่วยงานออกบัตร | หน่วยงานที่ออกบัตร |
| วันออกบัตร | วันที่ออกบัตร |
| วันหมดอายุ | วันหมดอายุ |
| ที่อยู่ | ที่อยู่ตามทะเบียนบ้าน |
| วันที่อ่าน | วันเวลาที่อ่านบัตร |

## เคล็ดลับการใช้งาน

### ✅ ควรทำ
- ✓ ใส่ข้อมูลโครงการและโรงเรียนก่อนเริ่มอ่านบัตร
- ✓ รอให้สถานะเป็นสีเขียว **"✓ อ่านสำเร็จ"** ก่อนถอดบัตร
- ✓ Export ข้อมูลเป็นระยะเพื่อป้องกันข้อมูลหาย
- ✓ ตรวจสอบจำนวนข้อมูลบนแถบสถานะ

### ❌ ไม่ควรทำ
- ✗ ถอดบัตรก่อนเห็นสถานะ **"✓ อ่านสำเร็จ"**
- ✗ เสียบบัตรเดิมซ้ำ (จะแจ้งเตือนว่าข้อมูลซ้ำ)
- ✗ ปิดโปรแกรมก่อน Export (ข้อมูลจะหาย)
- ✗ ถอด reader ขณะที่โปรแกรมทำงาน

## การแก้ปัญหา

### 1. โปรแกรมไม่พบ Reader
**วิธีแก้:**
- ตรวจสอบสาย USB
- คลิกปุ่ม **"🔄 รีเฟรช Reader"**
- ลองถอดและเสียบ reader ใหม่
- รีสตาร์ทโปรแกรม

### 2. อ่านบัตรช้า หรืออ่านไม่ได้
**วิธีแก้:**
- ตรวจสอบว่าบัตรใส่ถูกทิศทาง (ชิปหันเข้าหา reader)
- ทำความสะอาดชิปบัตร
- ลองถอดและเสียบบัตรใหม่
- ตรวจสอบว่า reader ทำงานปกติ

### 3. โปรแกรมค้าง
**วิธีแก้:**
- รอสักครู่ (อาจกำลังอ่านข้อมูล)
- ถ้ายังค้าง ปิดโปรแกรมและเปิดใหม่
- ตรวจสอบว่า reader ไม่มีปัญหา

### 4. ข้อมูลซ้ำ
**สาเหตุ:** เสียบบัตรเดิมอีกครั้ง
**วิธีแก้:** โปรแกรมจะแจ้งเตือน และไม่บันทึกข้อมูลซ้ำ

### 5. ภาษาไทยแสดงผิดในไฟล์ CSV
**วิธีแก้:**
- เปิด CSV ด้วย Excel → เลือก encoding "UTF-8"
- หรือใช้ Google Sheets (แสดงผลถูกต้องอัตโนมัติ)

## ข้อควรระวัง

⚠️ **ความปลอดภัยของข้อมูล**
- ข้อมูลบัตรประชาชนเป็นข้อมูลส่วนบุคคล
- เก็บรักษาไฟล์ CSV ให้ปลอดภัย
- ลบไฟล์เมื่อใช้งานเสร็จแล้ว

⚠️ **การใช้งาน**
- ไม่ควรปล่อยโปรแกรมทำงานทิ้งไว้นาน ๆ
- Export ข้อมูลเป็นประจำเพื่อป้องกันข้อมูลหาย
- ตรวจสอบความถูกต้องของข้อมูลก่อน Export

## ข้อกำหนดทางกฎหมาย

การใช้โปรแกรมนี้ต้องปฏิบัติตาม:
- พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562
- ต้องได้รับความยินยอมจากเจ้าของบัตรก่อนอ่านข้อมูล
- เก็บข้อมูลเฉพาะที่จำเป็น และระยะเวลาที่กำหนด
- รักษาความปลอดภัยของข้อมูล
